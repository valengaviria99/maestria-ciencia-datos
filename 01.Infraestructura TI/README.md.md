## Proyecto: ETL Pipeline con Data Fabric

Proyecto en equipo cuyo objetivo fue construir un pipeline en **Data Fabric** que integrara múltiples orígenes de datos (Excel, SQL y MongoDB), aplicara transformaciones sobre ellos y los consolidara en un único dataset final.

🔗 **Repositorio del proyecto:** https://github.com/MCD-Infrati/etlproject2025-2-e2-dataflow

**Mi rol:**
Estuve a cargo principalmente de la conexión con **MongoDB** como uno de los orígenes de datos. Además, participé activamente en la construcción general del pipeline y en el proceso de unificación de los distintos orígenes (Excel, SQL y MongoDB) en un solo dataset consolidado.

**Tecnologías / herramientas:**
- Microsoft Data Fabric
- MongoDB
- SQL
- Excel (como fuente de datos)

**Aprendizajes clave:**
- Integración de múltiples fuentes heterogéneas de datos en un pipeline ETL.
- Conexión y extracción de datos desde MongoDB dentro de un entorno de orquestación como Data Fabric.
- Transformación y unificación de datos con distinta estructura y origen en un dataset único y consistente.
